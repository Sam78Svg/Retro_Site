# Retro Site

A simple static website built with HTML.

## Overview

This project contains a lightweight retro-themed web page or collection of pages designed to be easy to open and host locally.

## Project Structure

- `index.html` — main entry page
- `assets/` — static files such as images, styles, or scripts (if present)

## Run locally

Because this is a static HTML project, you can view it by opening the `index.html` file directly in a browser.

Alternatively, you can serve it locally from the project folder using a simple HTTP server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- No framework or build step is required.
- Suitable for simple portfolio, landing page, or retro-themed static website projects.
